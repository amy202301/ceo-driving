# CEO 驾驶舱 · 简化版（中小企业老板的一屏经营助手）

> 给当地中小企业老板看的「经营驾驶舱」演示 + 交付系统。
> 一套网页，把公司每天的经营数据装进一块屏幕：推（今日简报）、看（经营总览）、决（决策建议）、令（指令中心），外加通知中心与数据接入页。
> 覆盖 5 个行业模板：商贸服务 / 制造业（化纤·铝·钢贸）/ 门店零售 / 房地产 / 餐饮。

## 这是哪个阶段的产品

按交付 SOP，产品分三形态：

| 形态 | 说明 | 适用 |
|---|---|---|
| 演示件（本仓库） | 静态 HTML，内置五行业示例数据，离线可用 | 谈单演示、获客 |
| 导入版 | 客户拖 Excel 进页面，自动出自己的图 | 第一单（收 1–2 万） |
| 服务器版 | 自动取数 + 企微每日推送 + 角色权限 | 月费形态（5 万起 + 月费） |

**本仓库是「演示件」形态**：用来给客户演示、拿客户的数据。拿到客户真实数据后，再生成导入版/服务器版。

## 目录结构

```
CEO驾驶舱/
├── docs/                       # ★ 部署用：轻量双文件版（GitHub Pages 源目录 /docs）
│   ├── index.html              #   入口页（107KB，引用本地 echarts.min.js）
│   └── echarts.min.js          #   本地 ECharts，零 CDN 依赖
├── CEO驾驶舱-演示版.html         # 单文件离线版（1.1MB，内联 ECharts，双击即用，适合微信/U盘发送）
├── demo/                       # 开发版（同 serve，轻量）
└── 交付手册/                    # 销售交付 SOP、视频脚本、数据模板 CSV
```

## 本地运行

**方式一（推荐，最快）**：双击 `CEO驾驶舱-演示版.html`，用 Chrome / Edge 打开即可，无需联网、无需服务器。

**方式二（本地服务）**：
```bash
cd docs
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```
> 注意：不要用 IE 打开，ECharts 5 不支持 IE。

## 部署到公网（GitHub Pages）

本仓库的 `docs/` 目录就是可直接托管的静态站点（也是 GitHub Pages 的源目录）：

1. 把本仓库推到你的 GitHub（已含 `docs/`）。
2. 仓库 → Settings → Pages → Source 选 `main` 分支、`/docs` 目录 → Save。
3. 几分钟后获得 `https://<你的用户名>.github.io/<仓库名>/` 公网链接，直接发给客户。

> 也可改用 `CEO驾驶舱-演示版.html` 单文件部署（更省事，但需手动上传）。

## 数据接入（给客户做真数据时）

见 `交付手册/数据模板/` 的 6 张 CSV + `字段说明.md`，以及 `交付手册/CEO驾驶舱-交付SOP.md` 的「阶段 3」。

## 注意事项

- 演示数据均为示例，**不含任何真实客户信息**。
- 给客户演示前，先切到客户所在行业的模板（顶部行业切换）。
- 谈单不要卖演示件，演示件的作用是拿到客户数据，那一版才是产品。
