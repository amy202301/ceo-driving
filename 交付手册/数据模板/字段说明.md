# 客户数据模板 · 字段说明

> 给客户看的文件。**原则：越少越好填。**
> 第一单只要前 4 张表（00–03）就能跑，04 和 05 能要到最好，要不到你帮客户写。

---

## 填表通则

- 用 Excel 打开这些 CSV，填好后**另存为 CSV UTF-8** 发回来（或直接把 Excel 发回来，我来转）
- **第一行是表头，不要改字段名**，也不要增删列
- 数字里**不要带单位**（写 `186`，不要写 `186条`；写 `12.6`，不要写 `¥12.6万`）
- 日期统一写 `月.日`（如 `10.30`）
- **建议脱敏**：客户名改成"客户A、客户B"，销售名改成"销售1、销售2"。签约后再上真实名称

## 00-KPI.csv · 顶部 4 张核心数字

| 列 | 填什么 | 例子 |
|---|---|---|
| 指标名 | 老板最关心的 4 个数，写 4 行 | 今日线索 |
| 数值 | 今天的数 | 186 |
| 单位 | 条 / 万 / 元 / % / 吨 | 条 |
| 对比说明 | 跟昨天或目标比 | +12 条 较昨日 |

**怎么挑这 4 个数？** 直接问老板："你每天早上最想看的四个数是什么？"他说的就是这 4 个。

## 03-部门进度.csv · 部门任务完成率

| 列 | 填什么 | 说明 |
|---|---|---|
| 部门 | 部门名 / 门店名 | 4–6 个 |
| 完成率 | 0–100 的整数 | 不要写 % |

颜色是自动的：**≥88 绿、75–87 黄、<75 红**。老板一眼看到谁在拖后腿。

## 04-重点事项.csv · 今日简报（最重要）

| 列 | 填什么 | 要求 |
|---|---|---|
| 级别 | 高危 / 关注 / 正常 | 高危建议 1–2 条，不要多 |
| 事项 | 一句话说清发生了什么 | **要具体，要有数字** |
| 责任部门 | 谁负责 | |
| 今日动作 | 建议做什么 | 写动作，不写评论 |
| 影响 | 涉及多少钱 | 写金额，最有说服力 |

**写法对比（这条决定项目成败）：**

| 差的写法 | 好的写法 |
|---|---|
| 销售跟进不及时 | 华信商贸（年预计 120 万）已 3 天无跟进记录 |
| 项目有点慢 | 官网改版实际进度 45%，落后计划 25 个百分点 |
| 成本偏高 | 投流单客成本从 18.4 涨到 22.4，超上限 21% |

**规则：每条必须有数字 + 必须有金额影响。** 老板愿意付钱买的是"判断"，不是"报表"。
