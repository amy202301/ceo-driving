# CEO 驾驶舱 · 从谈单到交付 手把手 SOP

> 适用：第一次给中小企业客户交付 CEO 驾驶舱
> 目标：60 分钟谈下第一单，28 天完成交付，第 3 个月转成月费
> 前提：你手上已有演示用的单文件 HTML（`CEO驾驶舱-演示版.html`）

---

## 总览：七个阶段

| 阶段 | 时长 | 你要做的事 | 结束时拿到 | 客户要配合 |
|---|---|---|---|---|
| 1 出门前 | 半天 | 备齐三样东西 | 演示文件 + 数据模板 + 问诊清单 | 无 |
| 2 第一次见面 | 60 分钟 | 演示 8 分钟 + 问诊 40 分钟 + 要数据 | 一份真实数据 + 明确需求 | 老板本人到场 |
| 3 做一版真数据 | 1–2 天 | 整理成模板，生成真实版驾驶舱 | 一版用客户真实数据跑的驾驶舱 | 提供 Excel |
| 4 第二次见面 | 30 分钟 | 给老板看他自己的数据 + 报价 | 签合同、收定金 | 老板拍板 |
| 5 实施 | 28 天 | 四周推进 | 正式上线 | 见每周清单 |
| 6 验收 | 半天 | 五条标准逐条过 | 验收单、尾款 | 老板签字 |
| 7 转月费 | 第 3 个月 | 从项目转服务 | 月度服务协议 | 老板续签 |

**第 3 阶段是整条链路的命门。** 老板看完演示只会说"挺好"，但看到自己的客户名字、自己的门店数字出现在屏幕上，反应完全不同——那一眼就是成交的瞬间。

## 阶段 2：第一次见面（60 分钟）

### 2.1 前 8 分钟：演示动线（照着说，别自由发挥）

> **第 1 屏 · 今日简报**
> "陈总，这是你昨天公司发生的事，就这 5 条。你不用问任何人。"

> **第 2 屏 · 经营总览**
> "以前这些你可能要开三个会、问四五个高管、等两三天。现在看一眼，30 秒。"

> **切到你客户所在的行业**
> "你们这行，看到的是这样。"（点行业按钮）

> **再切一个相邻行业**
> "做连锁的，是这样。"（点另一个，然后停住不说话）

> **第 3 屏 · 决策建议**
> "AI 已经帮你排好今天先做哪三件。你只需要点同意。"——**让老板亲手点一下**

> **第 4 屏 · 指令中心**
> "你自己说一句话试试。"——让老板现场输入，看它拆成任务。这是全场最震撼的一下

> **第 5 屏 · 数据接入**
> "你们现在用的这几个系统，我都能接进来。"——这一页是成交关键

**节奏要点**：前 8 分钟不要解释技术原理，不要讲架构。老板只关心"我看到什么"。技术细节留到他问。

### 2.2 中间 40 分钟：只问这 4 个问题

拿纸笔记，逐条写。

**问题 1：你现在是怎么知道公司每天发生什么的？**
> 听什么：他如果说"开会""问他们""看报表"，就记下来。
> 追问："那开会要多久？""等两天出来的数据还准吗？"
> 目的：让他自己说出痛点。**他说出来的，比你讲一百遍都有用。**

**问题 2：你现在最想知道、但一直知道不了的三件事是什么？**
> 让他说，不要替他说。典型答案：
> - 销售到底有没有在跟客户
> - 哪个项目其实已经延期了
> - 哪个人这几周没产出
> - 钱到底什么时候能回来
> 目的：**这三件事就是你要做的驾驶舱的第一屏内容。**

**问题 3：数据现在都在哪儿？**
逐个问，逐个记：

| 数据 | 在哪个系统 | 谁能导出 | 多久更新一次 |
|---|---|---|---|
| 销售/客户跟进 | | | |
| 订单/营业额 | | | |
| 项目/生产进度 | | | |
| 财务/回款 | | | |
| 审批/任务 | | | |

> 如果客户说"都在 Excel 里"，那是最好的情况——Excel 是最好接的。
> 如果客户说"在某某系统里"，问清三件事：能不能导出 Excel、有没有管理员账号、系统是哪家的。

**问题 4：这些数据谁能给我们？**
> 一定要**当场把那个人叫进来或加微信**。
> 很多项目死在这里：老板同意了，IT 或财务不给数据，拖三周就没下文了。

### 2.3 最后 12 分钟：要数据 + 报价

**要数据（关键动作）**
> "陈总，光看演示没意义。这样，**你把上个月的销售表和门店日报表发我，我下周给你做一版用你们真实数据跑的驾驶舱**，你看着觉得有用，我们再谈钱。"

这句话的杀伤力在于：你没逼他签，但他一旦给了数据，心理上就已经进入合作状态了。

**报价（他说多少钱时再报）**
先报单部门起步价，不要一上来报全公司：
> "我们先做一个部门，两周上线。**一次性 1 万 2，之后每月 3000 服务费**，包含数据维护、看板调整、每个月一次经营复盘会。做得好，再把其他部门接进来。"

**不要报年度、不要报全公司、不要报大数字。** 第一单的目的是进场，不是赚钱。

### 2.4 现场必记（写纸上）

- 老板最痛的三件事（原话）
- 数据在哪、谁能给
- 公司人数、部门数、门店/项目数
- 老板是否已经用企微/飞书/钉钉（决定推送方式）

## 阶段 3：做一版真数据（1–2 天）★ 成交关键

客户给了 Excel 之后，按下面做。

### 3.1 把客户的 Excel 整理成模板

客户的原始数据一定是乱的：合并单元格、多行表头、日期是文本、数字带货币符号。你要做的只有一件事：**把它变成我们这 6 张表的格式**。

模板在 `数据模板\` 文件夹，6 张表：

| 文件 | 管什么 | 客户要拿什么来填 |
|---|---|---|
| `00-KPI.csv` | 顶部 4 张核心数字卡 | 老板最关心的 4 个数 |
| `01-日趋势.csv` | 近 7 天趋势线 | 每天一个主指标（营业额/产量/来访数） |
| `02-结构占比.csv` | 饼图 | 分类 + 数值（来源/品类/渠道） |
| `03-部门进度.csv` | 部门进度条 | 部门名 + 完成率 |
| `04-重点事项.csv` | 今日简报表 | 需要老板关注的事 |
| `05-明细表.csv` | 下方明细表格 | 客户/订单/门店明细 |

### 3.2 行业对照（客户给你什么，你填什么）

| 行业 | 主指标（日趋势） | 结构占比 | 明细表 |
|---|---|---|---|
| 商贸服务 | 线索数 / 回款额 | 线索来源 | 客户跟进明细 |
| 制造业（化纤/铝/钢贸） | 日产量 / 吨 | 产品品类 | 订单与交期明细 |
| 门店零售 | 日营业额 | 渠道（堂食/外卖/团购） | 门店排名 |
| 房地产 | 来访 / 认购金额 | 渠道（分销/自然/老带新） | 楼盘去化 |
| 餐饮 | 日营业额 | 堂食/外卖/团购 | 门店排名 + 菜品成本 |

### 3.3 生成新版驾驶舱（把数据发给我）

整理好后，把 6 个 CSV 打包，连同下面这段话发给我：

```
按数据模板生成一版 CEO 驾驶舱。
行业：XXX
公司：XXX（人数/门店数）
老板最关心的三件事：1) XXX 2) XXX 3) XXX
附件是整理好的 6 个 CSV。
```

我会输出一个新的单文件 HTML，里面全部是客户真实数据。

> **保密提醒**：给客户要数据时，**建议让客户把客户名、人名换成代号**（"客户A""销售1"）。一是避免经营数据外泄的争议，二是客户更愿意给。等签约后再上真实名称。

### 3.4 拿到新文件后自检 5 条（必做）

- [ ] 打开的行业标签对不对（别给餐饮客户看制造业）
- [ ] 顶部 4 个 KPI 数字和客户 Excel 对得上
- [ ] 趋势线有 7 天数据，不是平的
- [ ] 今日简报的 5 条事项，是**这个老板真正会关心的**
- [ ] 全部文字里没有出现别的行业的词（比如给制造业客户看"线索""投流"）

第 4 条最重要：**AI 总结那段必须能戳中他。** 如果那 5 条事项是套话，老板一眼就看出来是假的，单子直接没。

## 阶段 4：第二次见面（30 分钟）

### 开场（照着说）

> "陈总，上次你说最想知道销售有没有在跟客户、哪个项目延期了。我用你们上个月的数据跑了一版，你看看是不是你要的。"

**然后闭嘴，让他自己看。** 不要解释、不要补充、不要抢话。他开始指屏幕问"这个数是怎么算的"，就说明成了。

### 报价三档（现场写给他）

| 档位 | 内容 | 价格 | 周期 |
|---|---|---|---|
| A 单部门 | 1 个部门 + 1 个数据源 + 老板手机推送 | 1–1.5 万 + 3000/月 | 2 周 |
| B 全公司 | 3–5 个部门 + 3 个数据源 + 角色权限 | 3–5 万 + 8000/月 | 4–6 周 |
| C 深度定制 | 系统集成 + 私有化部署 + 定制指标 | 8 万起 + 1.5 万/月 | 8–12 周 |

**第一单卖 A。** 说清楚一句话："先做一个部门，跑通了再加。"

### 合同必写（5 条）

1. **数据源清单**：哪个系统、哪些字段、谁提供、多久同步
2. **指标口径表**：每个指标一句话定义 + 计算公式
3. **验收标准**：3–5 条可验证的（例：每日 08:30 前推送到达；KPI 数字与客户系统一致）
4. **付款节奏**：签合同 50%，验收 50%；月费按月付
5. **服务范围**：月费包含什么（数据维护 + 每月迭代 + 每月一次复盘会），不包含什么（新增数据源另计）

## 阶段 5：实施四周

| 周 | 你做什么 | 交付物 | 客户配合 | 风险 |
|---|---|---|---|---|
| 第 0 周 | 半天访谈，确认口径 | 指标口径表（双方签字） | 老板 + 各部门负责人 | 口径没定死，后面反复改 |
| 第 1 周 | 打通 1 个核心数据源，跑出真实数字 | 能看的真实数据 | IT / 管理员开权限 | **权限卡住 → 提前约人** |
| 第 2 周 | 看板 + 企微每日推送上线 | 第一份自动推送的战报 | 无 | 老板不看 → 只推 3–5 条 |
| 第 3 周 | 试运行，按老板反馈校准 | 改 3–5 处口径 | **老板亲自用一周** | 老板不用 → 项目死 |
| 第 4 周 | 汇报会 + 验收 + 转月费 | 验收单 + 服务协议 | 老板签字 | 无 |

### 企微接入（第 2 周做这个）

最省事的做法（半天搞定，第一单必选）：
1. 在客户企微群里**添加一个群机器人**
2. 拿到机器人的 Webhook 地址
3. 每天 08:30 自动推一条战报（3–5 条重点事项 + 一个链接）
4. 点链接打开完整驾驶舱

要做正式应用（第二单起）：企微管理后台 → 应用管理 → 自建 → 创建应用 → 拿 CorpID / Secret / AgentId → 配置可信域名 → 调应用消息接口。**提前让客户把管理员叫到现场**，否则卡三天。

### 权限（第 2–3 周）

| 角色 | 能看 | 不能看 |
|---|---|---|
| 老板 | 全公司、所有人明细 | — |
| 总监/店长 | 本部门汇总 + 本部门员工 | 其他部门、成本、工资 |
| 员工本人 | 只看自己的客户和任务 | 同事数据 |

**两条心法**：
- 员工端必须给好处（自动写跟进记录、自动提醒、自动生成周报）。**员工没好处，数据就是假的。**
- 对外永远叫"经营助手"，**不要叫"监控"**。员工听到监控会立刻开始应付你。

## 阶段 6：验收（半天）

逐条过这 5 条，过不了就别收尾款：

- [ ] 每日 08:30 前，战报准时推送到老板企微
- [ ] 顶部 4 个 KPI 数字，与客户系统逐条核对一致（抽查 3 天）
- [ ] 每个数字能点回明细
- [ ] 三种角色的权限正确（用员工账号实测）
- [ ] 老板已连续使用 7 天以上

---

## 阶段 7：转月费（第 3 个月）

**什么时候提**：第二个月复盘会上。老板看到数据帮他省钱/抓到人之后，当场提。

**怎么说**：
> "陈总，这个月系统帮你抓到两个问题（举具体事）。下个月我想做两件事：一是把 XX 部门也接进来，二是每月给你出一份经营复盘。新增部门 8000，服务费不变。"

**月费是命根子。** 一次性项目活不过第二年，这是所有 BI 项目的共同结局。

## 附录 A：常见拒绝与应对

| 老板说 | 真实意思 | 你怎么答 |
|---|---|---|
| "我们再看看" | 没被戳到 | "那你最想看到哪个数？我做给你看" |
| "我们有 ERP 了" | 觉得重复 | "ERP 是记账的，这是告诉你哪件事在漏钱。不冲突，我从 ERP 里取数" |
| "员工会抵触" | 怕团队反弹 | "所以员工端我做了自动写日报——他省事，你看到真相，两边都划算" |
| "多少钱？太贵" | 想砍价 | "先做一个部门 1 万块，两周上线。做完你觉得没用，钱退你" |
| "数据安全吗" | 怕外泄 | "可以部署在你们自己的服务器；演示阶段用代号数据，不碰真实客户名" |
| "我们太小了用不上" | 觉得不配 | "3–5 人的店照样用，就是营业额、成本、复购三个数。越小越要盯" |

## 附录 B：第一个客户怎么挑

同时满足这三条才做，缺一不碰：

1. **老板亲自抓业务**（销售/生产/门店，而不是甩手给副总）
2. **已经有数据**（哪怕只是 Excel）
3. **愿意给你一周试用**

不要挑最大的客户。大公司流程长、IT 卡、验收难，你的第一个项目会死在里面。
